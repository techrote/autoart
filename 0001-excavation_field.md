# AUTOART

## 001 — Excavation Field

A single-file, dependency-free generative artwork assembled from recurring ideas across the wider `techrote` repository set.

Open `0001-excavation_field.html` directly in a modern browser. No build step, package manager, server, external assets, telemetry, or network access is required.

### Controls

- `Space` — pause / resume
- `R` — move to the next deterministic seed
- `S` — save the current frame as PNG
- `H` — hide / show the minimal interface
- pointer movement — temporarily perturbs the field like a tool head; the work relaxes back toward its canonical motion

The starting state is deterministic from seed `0xA17F2026`. Simulation advances on a fixed step; display refresh rate does not define the artwork's state progression.

## What is in the piece

This is not a literal mash-up of project assets. It synthesizes repeated visual and technical ideas from the repositories into one composition:

- **ArtMiner** — deterministic procedural systems, fixed-step evolution, mutation and reproducible state.
- **FIELDWEAVER** — vector fields, emitters, deposition trails, sparse authored structure and the idea of behaviour being painted rather than pixels.
- **FAULTMINE / Invalid Image / Recovered Prototype** — controlled faults, channel-like displacement, temporal residue and corruption as an intentional instrument rather than accidental undefined behaviour.
- **LINEIMATION / Recovered Fractal Generator** — slow recursive filaments, flow-through-space, recurrence and motion that changes the interior without requiring rapid whole-scene cuts.
- **CyberSand / sandimations / ESPsand** — sparse material work, phased activity, deposition cells and a world that only visibly spends computation where something is happening.
- **Steel Moth / ShadeDoomVK** — occlusion, restrained bloom, pseudo-depth and darkness treated as geometry rather than merely a background colour.
- **XenoField** — void halos, spectral membranes, controlled feedback and alien volumetric atmosphere.
- **ASCIIomium / PNG2ANSI / pyANSI / GlyphPaint / GlyphPoint** — terminal-cell quantisation, half-block/glyph texture and the conversion of continuous imagery into coarse symbolic structure.
- **radiCADSAC / EdgeCraft / OrcaSlicer-PlanePath** — machined contours, support geometry, ordered coverage and toolpath-like traces.
- **Brachistochrone Lab** — the amber cycloidal cut crossing the lower field.
- **PlasmaTerm** — complexity emerging from deterministic interacting waves rather than random visual noise.

The central dark form is an **excavated absence**: field lines wrap around it, fault bands mis-register its surroundings, machining paths measure it, and recursive traces appear to grow from its edge. The right-side glyph region is a deliberately incomplete terminal “biopsy” of the same field rather than a separate UI panel.

## Intent

The piece is built around a tension that recurs across the projects: exact deterministic machinery being used to create things that look unstable, organic, damaged or unknowable.

The result should feel less like a software demo and more like a machine quietly discovering a ruin.
